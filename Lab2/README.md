## Защита: ответы на вопросы

**Что такое flexbox и grid?**
Flexbox — одномерная модель раскладки (вдоль одной оси), grid — двумерная (строки и колонки одновременно). В работе сетка блюд сделана через grid, а содержимое блюда — через flex.

**Как выровнять кнопки по одной линии при разной длине названий?**
Блок блюда — flex с вертикальным направлением. У веса/объёма стоит `margin-top: auto`, который забирает всё свободное место сверху и прижимает вес и кнопку к низу — независимо от высоты названия.

**Что делает media-запрос?**
Меняет стили в зависимости от ширины экрана. При `max-width: 800px` сетка становится 2 колонки, при `max-width: 600px` — 1 колонка, а меню — вертикальным.

**Зачем `#active`?** Чтобы выделить текущую страницу цветом tomato.

**Как работает липкий футер?** `body` — flex-столбец высотой 100%, `main` растягивается (`flex: 1`), футер остаётся внизу даже при коротком контенте.
