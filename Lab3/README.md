# Лабораторная работа №3. Форма заказа

Страница «Собрать ланч» (`lunch.html`) с формой заказа. Форма отправляется методом POST на `https://httpbin.org/post`.

## Защита: ответы на вопросы

**Как отправить форму на httpbin?**
У тега `<form>` указаны `action="https://httpbin.org/post"` и `method="POST"` — браузер сам отправляет данные, на httpbin видно все отправленные значения.

**Как запретить отправку без нужных значений?**
`required` на обязательных полях и селектах. Пока в каждом селекте не выбрана опция с заполненным `value` и не заполнены обязательные поля, браузер не отправит форму.

**Зачем пустая опция «Выберите суп»?**
Опция по умолчанию имеет `value=""`, остальные — логичные значения (например, `borsch`). Пустое значение приводит к срабатыванию `required`.

**Как связать label с полем?**
Атрибут `for` у label должен совпадать с `id` поля. Для чекбокса и радио input вложен прямо в label.

**Какова структура формы?** `section.order` с `h2` и `form` (grid на 2 колонки): блок «Заказ клиента» (3 селекта + textarea) и блок «Данные клиента» (поля, чекбокс, радио, время, кнопки reset/submit).
